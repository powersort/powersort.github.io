pen down · a one-stroke drawing game

Draw every line once.
Never lift the pen.

Each picture is made of dots and lines. Put the pen on a dot and trace the lines, each exactly once, without lifting the pen. Passing through a dot again is fine; going over a line twice is not. Some pictures cannot be drawn like that — if you are sure, say can’t be done, but a wrong claim counts as a mistake. Your time and your mistakes go on the leaderboard.

import / export a picture

The export is valid Python: dots maps each name to a position (y grows downwards), lines lists pairs of dots, an optional start fixes the first dot, and trail is the drawing so far as the dots the pen visits. With parallel lines, trail_lines gives the line numbers as well. Import also takes JSON with the same fields, so you can make your own pictures.
